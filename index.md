# WAAdminBot rclone

WAAdminBot rclone adalah aplikasi pribadi milik Muhamad Nursidik Almalik. Aplikasi ini hanya dipakai oleh pemiliknya sendiri untuk mencadangkan (backup) data bot absensi dan keuangan usahanya ke Google Drive milik pemilik, memakai program rclone.

Aplikasi ini tidak tersedia untuk umum dan tidak melayani pengguna lain.

## Kebijakan Privasi

Data apa yang diakses: hanya file yang dibuat oleh aplikasi ini sendiri di Google Drive pemilik (izin drive.file). Aplikasi tidak bisa melihat file lain di Drive.

Untuk apa data dipakai: menyimpan salinan cadangan data absensi, buku kas, foto nota, dan slip gaji milik pemilik.

Berbagi data: data tidak dijual, tidak dibagikan, dan tidak dikirim ke pihak ketiga mana pun. Data hanya berpindah antara server milik pemilik dan Google Drive milik pemilik.

Penyimpanan dan penghapusan: data disimpan di Google Drive pemilik dan dapat dihapus kapan saja oleh pemilik. Akses aplikasi bisa dicabut kapan saja di myaccount.google.com/permissions.

Kontak: muhamadnursidikalmalik@gmail.com

## Ketentuan Layanan

Aplikasi ini disediakan apa adanya untuk penggunaan pribadi pemilik. Tidak ada layanan untuk pihak lain.
